# BEST Fitness

แอปต้นแบบ Next.js สำหรับวางแผนการฝึก ออกแบบโปรแกรมเอง ติดตามข้อมูลร่างกาย และบันทึกแผนโภชนาการ ออกแบบจาก Figma BEST และเอกสาร `REQUIREMENTS.md`

## เปิดใน VS Code

1. ติดตั้ง Node.js รุ่น LTS ที่รองรับ Next.js 16
2. เปิดโฟลเดอร์นี้ใน VS Code
3. เปิด Terminal แล้วรัน `npm install`
4. รัน `npm run dev` และเปิด `http://localhost:3000`

หากยังไม่ตั้งค่า Supabase แอปทำงานในโหมดทดลองและเก็บข้อมูลในเบราว์เซอร์ปัจจุบัน

## ต่อ Supabase

1. สร้างโปรเจกต์ Supabase
2. คัดลอก `.env.example` เป็น `.env.local` แล้วกรอก Project URL และ Publishable key จากหน้า Connect ของโปรเจกต์
3. schema หลักถูกติดตั้งในโปรเจกต์ Supabase `BESTDB` แล้ว; หากตั้งค่าโปรเจกต์ใหม่ ให้รัน SQL ใน `supabase/migrations/20261114160402_best_fitness_core_schema.sql` ผ่าน Supabase SQL Editor
4. รีสตาร์ต dev server แล้วสมัคร/ลงชื่อเข้าใช้จากแท็บ Profile

อย่าใส่ Secret/service-role key ในตัวแปร `NEXT_PUBLIC_*` หรือในแอปฝั่งเบราว์เซอร์ ตารางข้อมูลเปิดใช้ RLS และจำกัดแถวตาม `auth.uid()` แล้ว

## สิ่งที่ทำงานในต้นแบบ

- แดชบอร์ดฝึกตามหน้าจอ Figma พร้อมสรุปโปรแกรมและเช็กลิสต์เซต
- สร้างโปรแกรมเองจากรายการท่าและแก้เซต/น้ำหนัก/จำนวนครั้ง
- ตัวช่วยสร้างแผนฝึกแบบ AI จำลองในเครื่อง (ยังไม่ได้เรียกโมเดล AI ภายนอก)
- บันทึกข้อมูลร่างกายและดูรายการย้อนหลัง
- แบบสอบถามโภชนาการและสร้างตัวอย่างแผนรายวัน
- โหมดทดลองแบบ localStorage หรือบันทึกข้อมูลผ่าน Supabase เมื่อเชื่อมต่อและลงชื่อเข้าใช้

ค่าพลังงานและสารอาหารเป็นค่าตัวอย่างสำหรับต้นแบบ ไม่ใช่คำแนะนำทางการแพทย์หรือโภชนาการที่ผ่านการรับรอง
